# El contexto de un fragmento

Ficha propia de KeepAnalog para distinguir una cita del contexto consultado y una duda pendiente.

Esta rama se usa exclusivamente en Render Static Sites. No modifica la publicación de GitHub Pages desde main. Editar index.html y publicar manualmente en Render. No dependencias, variables de entorno, formularios remotos, analytics ni builds de aplicación. Las notas de visitantes no se almacenan ni transmiten.
